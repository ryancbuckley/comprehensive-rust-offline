Using the course offline

This copy of Comprehensive Rust compiles and runs its code examples in your browser, so it works without a network once your browser has a copy of it. Back to the course.

Save it in your browser

Pages you have opened are kept automatically, and so is the Rust compiler once you have run an example. To keep everything, including every page and search, save the course:

Checking what this browser has saved…

Keep this page open while it saves. If it stops, press Save again: it continues where it left off. When a new version of the course is published, your browser fetches the changed files the next time you use them online; press Save again to fetch all of them at once.

Safari deletes what a website has stored if you don't visit it for about a week. To keep the course longer, add it to the Dock (on a Mac: File › Add to Dock) or to the Home Screen (on an iPhone or iPad: Share › Add to Home Screen), open it from there, and save it again there: it keeps its own copy.

Or download it

If your browser can't keep the course, for example in a private window, download a copy and serve it from your own computer. You need Python 3.

  1. Download the course as a ZIP file (about 130 MB, with every language) and unzip it.
  2. In a terminal, in the unzipped folder, run python3 -m http.server 8000.
  3. Open http://localhost:8000/.

Opening the files directly (a file:// address) doesn't work: browsers only run the compiler's workers on pages that come from a web server.
